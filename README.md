### 👨‍💻 Tentang Saya

Halo! Saya **Alviensyah Mohammad**, mahasiswa jurusan **Teknik Informatika**, **Fakultas Ilmu Komputer (FILKOM) Universitas Brawijaya**. Sebagai seorang penyandang disabilitas Tuli (**Deaf Developer**) dan **Linux Enthusiast**, saya memiliki dedikasi dan passion mendalam di bidang rekayasa perangkat lunak, khususnya pengembangan **Web**, **Mobile Application**, serta eksplorasi sistem operasi **Linux**.

- 🎓 **Pendidikan**: Mahasiswa S1 Teknik Informatika, Fakultas Ilmu Komputer (FILKOM) — **Universitas Brawijaya**
- 🤟 **Identitas**: **Penyandang Disabilitas Tuli (Deaf Developer)** — Membuktikan bahwa keterbatasan bukan halangan untuk terus berkarya, belajar, dan berinovasi di dunia teknologi.
- 🐧 **Linux Enthusiast**: Sangat tertarik dan aktif mengeksplorasi berbagai distro Linux seperti **Ubuntu**, **Arch Linux**, **Fedora**, hingga **Gentoo**.
- 💻 **Fokus Saat Ini**: Membangun aplikasi web interaktif, modern, dan aplikasi mobile yang user-friendly serta aksesibel.
- 🚀 **Kolaborasi**: Sangat terbuka untuk kolaborasi proyek open-source, peluang magang, maupun kerja sama menarik lainnya.
